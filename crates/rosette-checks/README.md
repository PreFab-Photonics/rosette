# rosette-checks

Design checks for photonic layouts: hierarchical connectivity nodes, port compatibility, and annotated bend-radius validation.

- **Depends on:** rosette-core, rosette-route, rstar
- **Consumed by:** rosette-python

See the workspace [`AGENTS.md`](../../AGENTS.md) for the crate map, and `cargo doc -p rosette-checks --open` for the API reference.
