Immutable diagnostic for one bend generated by a [`Route`](./Route).

Import with `from rosette.routing import BendInfo`.

`Route.bends` returns these records. They describe generated route geometry;
they are not generic Cell metadata and cannot be constructed directly.

```python
from rosette.routing import Route

route = Route(1, bend_radius=10.0)
route.start_at(0, 0)
route.to(20, 0)
route.to(20, 5)
route.end_at(40, 5)

for bend in route.bends:
    print(bend.radius, bend.position, bend.requested_radius)
```

## Attributes

<PyAttribute name={"radius"} type={"float"}>

Effective bend radius in microns after any automatic reduction.

</PyAttribute>

<PyAttribute name={"position"} type={"Point"}>

Corner position in the route cell's local coordinate system.

</PyAttribute>

<PyAttribute name={"requested_radius"} type={"float | None"}>

Originally requested radius when the router reduced it, otherwise `None`.

</PyAttribute>
